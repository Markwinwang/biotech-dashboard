# SLIDE 1: EXECUTIVE SUMMARY

## 核心结论：诺华需在三大战略方向发力，以巩固血液肿瘤领先地位

### 关键洞察 | Key Insights

| 战略优先级 | 核心行动 | 预期价值 |

# SLIDE 3: MDS 深度分析 | MDS DEEP DIVE

## MDS 领域：Telomerase 与 BCL-2 成为突破性治疗两大支柱

### Top 3 最具前景 MoA

#### 1️⃣ Telomerase Inhibition (端粒酶抑制) — ⭐ HIGH PRIORITY

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Imetelstat (寡核苷酸) |
| **阶段** | ✅ Approved / Launch (IMerge Phase 3) |
| **关键数据** | 低危MDS ESA难治患者: 8周TI率 ~40%，缓解持久性优异 |
| **机制优势** | 靶向恶性克隆无限增殖能力 |
| **竞争格局** | Geron 独占，竞争较少 |

#### 2️⃣ BCL-2 Inhibition — 高危 MDS 核心

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Venetoclax + HMA |
| **阶段** | Phase 3 (VERONA trial) |
| **未满足需求** | HR-MDS 的 OS 改善，HMA 单药效果有限 |
| **竞争格局** | AbbVie/Roche 领跑 |

#### 3️⃣ TGF-β Ligand Trap — 贫血改善

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Luspatercept / Ker-050 (Elritercept) |
| **阶段** | Approved (Luspa) / Phase 2/3 (Ker-050) |
| **差异化** | Ker-050 对 non-RS 及血小板减少患者更广 |
| **竞争格局** | BMS 主导，Keros 为挑战者 |

### Watch List (7个关注靶点)

```
┌──────────────────┬──────────────────┬──────────────────┐
│ IRAK4 抑制剂     │ TIM-3 抗体       │ CD47/SIRPα       │
│ (剪接因子突变)   │ (Sabatolimab)    │ (Next-gen安全型) │
├──────────────────┼──────────────────┼──────────────────┤
│ 口服 Decitabine  │ Menin 抑制剂     │ RARA 激动剂      │
│ (便利性)         │ (NPM1m/KMT2Ar)   │ (Tamibarotene)   │
├──────────────────┴──────────────────┴──────────────────┤
│              NLRP3 抑制剂 (炎症驱动型)                  │
```

# SLIDE 4: AML 深度分析 | AML DEEP DIVE

## AML 领域：Menin 抑制剂将重塑 30-40% 患者的治疗格局 — 诺华必须入场

### Top 3 最具前景 MoA

#### 1️⃣ Menin-KMT2A Inhibition — ⭐⭐⭐ HIGHEST PRIORITY

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Revumenib (Syndax), Ziftomenib (Kura) |
| **阶段** | NDA / Pivotal Phase 2 |
| **关键数据** | R/R NPM1m/KMT2Ar AML: CR/CRh >30% |
| **机制优势** | 直接逆转白血病干细胞转录程序 |
| **临床价值** | HSCT 桥接治疗的核心选择 |
| **市场规模** | 覆盖 30-40% AML 患者，峰值 >$1.5B |

```
⚠️ 战略警示：这是确定的下一个 Blockbuster
   诺华若不入场，将在 AML 核心市场边缘化
```

#### 2️⃣ Next-Gen FLT3 Inhibition

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Quizartinib, Tuspetinib |
| **差异化** | 克服 1/2 代耐药，覆盖 ITD/TKD 全谱 |
| **独特价值** | Tuspetinib 靶向 SYK/JAK，对 Venetoclax 耐药有效 |

#### 3️⃣ CD123 x CD3 Bispecifics

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Flotetuzumab, Vibecotamab, SAR443579 |
| **阶段** | Phase 1/2 |
| **优势** | CD123 表达普遍，双抗 vs ADC 毒性谱不同 |
| **挑战** | CRS 毒性管理 |

### Watch List

| 靶点 | 机制 | 开发者 |
|-----|------|-------|
| E-selectin (Uproleselan) | 破坏骨髓微环境保护 | GlycoMimetics |
| CD70 | 白血病干细胞新靶点 | — |
| CDK9 | 阻断转录延伸 | — |
| IDH1/2 Next-gen | 脑渗透更好，覆盖耐药 | — |
| CAR-T/NK (CLL-1/CD33/CD123) | 克服脱靶毒性 | 多家 |

# SLIDE 5: MF 深度分析 | MF DEEP DIVE

## MF 领域：诺华凭借 Pelabresib 占据领先地位 — 需巩固并扩大优势

### Top 3 最具前景 MoA

#### 1️⃣ BET Inhibition — ⭐ NOVARTIS LEAD ASSET

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Pelabresib |
| **阶段** | NDA / Phase 3 (MANIFEST-2) |
| **关键数据** | 联合 Rux 在 SVR35/TSS50 显著优于 Rux 单药 |
| **突破性价值** | 改善贫血 + 骨髓纤维化程度 = **生物学修正潜力** |
| **机制** | 下调 NF-κB 和 TGF-β 通路 |

```
✅ 战略优势：Novartis (via MorphoSys) 拥有该领域最强资产
   应作为 MF 领域持续扩张的基石
```

#### 2️⃣ BCL-xL Inhibition

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Navitoclax |
| **阶段** | Phase 3 (TRANSFORM) |
| **价值** | 联合 JAKi 诱导更深细胞凋亡 |
| **目标人群** | JAKi 反应不佳/进展患者 |
| **风险** | ⚠️ 血小板减少副作用 |

#### 3️⃣ ACVR1/JAK1/JAK2 Inhibition

| 维度 | 详情 |
|-----|------|
| **靶点/药物** | Momelotinib |
| **阶段** | ✅ Approved |
| **独特价值** | ACVR1 抑制降低 Hepcidin，改善 MF 贫血 |
| **竞争** | GSK (Sierra Oncology) 拥有 |

### Watch List
